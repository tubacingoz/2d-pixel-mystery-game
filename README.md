# 2D Pixel Mystery & Farming RPG: Concept & UI/UX Design

**Project Overview & Vision**
This repository serves as the core Game Design Document (GDD) and UI/UX asset library for an upcoming 2D pixel art indie game. Blending resource-management mechanics with narrative-driven mystery, this project demonstrates product vision, user journey mapping, and visual design execution.

**Role:** UI/UX Designer & Game Concept Analyst
**Design Tools:** Figma (Interactive Components, HUD), Krita (2D Pixel Art, Character Assets)

## Core Game Mechanics & Product Requirements
Approaching game design with an analytical mindset, the core features are structured as product requirements:
* **Resource Management:** Day-time economy involving farming, crafting, and strategic energy allocation.
* **Investigative Dialogue System:** Dynamic NPC interactions managed through branched narrative decision trees.
* **Day/Night Cycle:** A dual-state environment shifting between cozy farming (Day) and stealth/investigation (Night).

## Narrative Design & World Building
The surface-level idyllic nature of the town is disrupted by sudden soil degradation and unexplained nocturnal events. The protagonist must balance daily survival with uncovering the town's deep-rooted enigma, providing continuous engagement through environmental storytelling.
