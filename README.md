# 2D Pixel Mystery & Farming RPG: Concept & UI/UX Design

**Project Overview & Vision**
This repository serves as the core Game Design Document (GDD) and UI/UX asset library for an original 2D pixel art indie game. Blending cozy resource-management mechanics with psychological mystery and deduction, this project demonstrates product vision, user journey mapping, and visual design execution.

The game explores a seemingly utopian fairy society where suppressed emotions manifest as physical corruption on the land. The player must balance restoring the environment by day with investigating the dark truth by pitch-black night.

**Role:** UI/UX Designer, Game Concept Analyst & Pixel Artist
**Design Tools:** Figma (Interactive Components, HUD), Krita (2D Pixel Art, Character Assets, Animation)

## Core Game Mechanics & Product Requirements
Approaching game design with an analytical mindset, the core features are structured as an interconnected gameplay loop:

* **The Void Craters (Environmental Puzzle):** Repressed emotions tear physical holes in the town's fabric. The player must cultivate specific "healing crops" to seal these craters, restore the farmable land, and return stolen emotions to NPCs.
* **Investigative Deduction System (Day):** Dynamic NPC interactions via branched narrative trees. Players must cross-reference alibis and observe subtle behavioral shifts in NPCs to deduce who suffered a "corrupted episode" the previous night.
* **Cursor-Driven Stealth & Discovery (Night):** In pitch-black environments, the player's cursor acts as a localized light source, revealing neon-colored "emotion trails" left by victims, leading to crucial clues without traditional pixel-hunting.
* **Resource Economy:** Balancing stamina and time between classic cozy farming, crafting investigative tools, and brewing emotional remedies.

---

##  Narrative Design & World Building
On the surface, the fairy town is a flawless utopia governed by strict roles (The "Perfect Stage"). However, this illusion forces citizens to suppress their true feelings. These stolen/suppressed emotions are secretly harvested, leaving victims numb by day and creating chaotic environmental anomalies by night. 

The narrative provides continuous engagement through environmental storytelling, challenging the player to prove that true harmony requires accepting negative emotions rather than erasing them.
